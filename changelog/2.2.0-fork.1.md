# BetterHud 2.2.0-fork.1

First public release of the Client-Side Animation Fork for BetterHud:
- GPU-Accelerated Core Shader client-side animations (144+ FPS, sub-tick precision).
- Lossless 24-bit RGB exact text mode with zero quantization error.
- Dual-copy exact text shadow support with dynamic 24000 divisor modulus.
- Independent dispatcher IDs for client and server layouts.
- Runtime per-player `/hud animation-mode` command and automatic Bedrock server fallback.
- Offline and hardware verification test suite.
