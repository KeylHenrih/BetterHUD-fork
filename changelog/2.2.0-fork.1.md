# BetterHud 2.2.0-fork.1 (Pre-Release)

Специализированный форк BetterHud с аппаратным рендерингом анимаций HUD на GPU клиента через Minecraft Core Shaders.

### Что нового:
- **Плавные анимации на клиенте (144+ FPS):** анимации перемещения, затухания и заполнения баров интерполируются на каждом кадре дисплея по внутриигровому `GameTime`.
- **Точный 24-битный цвет текста (`text-client-mode: exact`):** честный спектр RGB (16 777 216 цветов) без дискретных палитр.
- **Цветная тень текста (`text-shadow-mode: dual`):** схема с двумя копиями текста с динамическим делителем M для сохранения точного цвета тени.
- **Устранение ложного кадра (wrap-around flash):** квады принудительно схлопываются за экран при отрицательном времени `elapsed < 0.0`.
- **Разделение диспетчерских ID:** независимый пул ID для клиентских и серверных лейаутов.

### Установка:
1. **Удалите оригинальный BetterHud** из папки `plugins/`. **Не запускайте оба JAR-файла одновременно.**
2. Поместите `BetterHud-bukkit-2.2.0-fork.1.jar` в папку `plugins/`.
3. Запустите сервер и примените ресурспак, сгенерированный плагином.
4. Настройки шейдеров находятся в `plugins/BetterHud/shader.yml`.

### Статус проверок:
- **Проверено в игре:** Реальный клиент Minecraft **26.1.2** (сервер Purpur 26.1.2, ванильный клиент и Fabulously Optimized при GUI scale 2 и 3).
- **Не проверялось в игре:** Сессии с несколькими одновременными игроками для `/hud animation-mode`, реальные клиенты Bedrock Edition (Geyser/Floodgate), клиенты версий 1.21.4–1.21.6 и 26.2–26.3 (проверены компилятором GLSL offline).

### Откат на серверный режим:
При любых несовместимостях установите в `plugins/BetterHud/shader.yml`:
```yaml
animation-mode: server
```
Плагин перейдёт в 100% ванильный режим работы, полностью идентичный оригинальному BetterHud.

> [!WARNING]
> **Параметр `delete-shaders-on-start`:** по умолчанию установлен в `false`. Не включайте его без необходимости, если вносите ручные изменения в шейдеры плагина (при `true` существующие шейдеры ротируются в архив `shaders.bak-<timestamp>`).
